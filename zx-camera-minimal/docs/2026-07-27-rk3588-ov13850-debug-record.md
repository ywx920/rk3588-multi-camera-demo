# ZX2603-2 RK3588 OV13850 调试记录与后续处理建议

## 1. 文档信息

- 日期：2026-07-27
- 板卡：ZX2603-2
- SoC：RK3588
- 内核：Linux 5.10.160
- 系统：Ubuntu 20.04.6 LTS，aarch64
- 摄像头：OV13850，当前主路 `/dev/video22`
- 模组：`ZC-OV13850R2A-V1`
- 镜头：`Largan-50064B31`
- 当前模式：2112×1568、NV12、约30 FPS
- RKAIQ：AIQ v5.0x3.0，IQ Parser Calib v1.4.8

## 2. 当前结论

### 2.1 已解决

1. `/dev/video22`可以通过V4L2 MMAP稳定采集。
2. 支持`VIDEO_CAPTURE_MPLANE`，实际格式为单平面NV12。
3. 2112×1568 NV12单帧大小为4,967,424字节。
4. 可以连续采集、保存RAW、统计FPS和序号，并通过Ctrl+C安全退出。
5. 采集程序退出后可以立即重新打开设备。
6. RKAIQ能够保持运行，systemd服务状态为`active (running)`。
7. ISP21 IQ与ISP30不兼容导致的RKAIQ崩溃已绕过。
8. LSC分区长度错误已经修正，不再出现`ALSC:E`。
9. ISP30兼容IQ v3已经安装，V4L2主链路约29～30 FPS。
10. 板端测试工具已经固定存放在用户目录，不再依赖`/tmp`中的工程文件。

### 2.2 尚未解决

1. 当前画面严重偏暗，亮灯区域偏黄，暗部大面积压黑。
2. 当前ISP30 v3是兼容性文件，不是该ZC+Largan模组的正式标定IQ。
3. Windows RKISP Tuner缺少RK3588 AIQ v5.0x3.0配置。
4. 2026版和2023版`rkaiq_tool_server`均未能与现有Windows Tuner完成稳定握手。
5. 尚未完成AE、AWB、CCM、Gamma、DRC、LSC等正式标定。
6. 因画质未通过，暂不应把Qt实时预览或Web预览作为下一验收阶段。

### 10.4 最终原因

板端曾使用AIQ v5.0x1.3，之后从其他来源移植为AIQ v5.0x3.0。

当前Windows Tuner的RK3588配置只有：

```text
v5.0x1.2-rc1
v5.0x1.2-rc5
v5.0x1.3
v6.x
```

没有：

```text
RK3588 v5.0x3.0
```

虽然资料中存在RV1106 v5.0x3.0配置，但不能用于RK3588。当前失败不是网络问题，而是以下组件
不是同一发布套件：

```text
librkaiq / rkaiq_3A_server
rkaiq_tool_server
RKISP_Tuner.exe
RK3588 UI Module
RK3588 default IQ
module list
```

## 11. 后续推荐方案

### 11.1 首选方案：取得完整的RK3588 v5.0x3.0工具链

向AIQ v5.0x3.0移植来源索取：

```text
RK3588_UI_Module_v5.0x3.0.json
defaultIQ_RK3588_v5.0x3.0.json
modulelist_v5.0x3.0.ini
匹配的RKISP_Tuner.exe
匹配的rkaiq_tool_server
匹配的librkaiq.so和rkaiq_3A_server版本说明
```

不要使用RV1106配置替代。

### 11.2 备选方案：整体迁移到一套工具齐全的版本

如果无法取得v5.0x3.0工具，应整体迁移以下组件，而不是单独替换二进制：

```text
librkaiq
rkaiq_3A_server
rkaiq_tool_server
RKISP Tuner配置
基础IQ
```

升级前必须保留当前可运行系统和IQ回滚路径。

### 11.3 临时方案：离线单变量A/B测试

保留v3作为稳定基线。每次只修改一个模块，先从AE开始。

第一版可以保守测试：

```json
"DySetpoint": [65, 65, 60, 55, 50, 45]
```

测试候选IQ时不要安装：

```bash
sudo CANDIDATE_IQ=/home/zxwy/zx-camera-tools/iq/候选文件.json \
  bash /home/zxwy/zx-camera-tools/scripts/board_iq_compat_test.sh
```

不要传入`--install-on-pass`。脚本完成后恢复当前v3，只保留候选帧和报告。

AE候选的初步量化目标：

```text
Y mean       : 40～80（第一轮）
Y <= 16      : 低于20%
Y >= 235     : 不明显超过5%
Average FPS  : 不低于25
曝光/增益    : 不持续振荡
```

AE通过后再依次处理：

1. AWB；
2. CCM；
3. LSC；
4. Gamma/DRC；
5. 降噪和锐化。

不要在同一版IQ中同时修改多个模块。

## 12. 回滚与保护

当前已安装v3的确认命令：

```bash
sha256sum \
  /etc/iqfiles/ov13850_ZC-OV13850R2A-V1_Largan-50064B31.json
```

预期：

```text
17477115021e7f2c5c7632ab3af1df5c141952935547a45de6f7905d66b554c2
```

服务确认：

```bash

```

任何新IQ在正式安装前必须满足：

1. RKAIQ启动后持续运行；
2. 无段错误、`lost smartRun`、AWB或ALSC致命错误；
3. 连续采集至少300帧；
4. FPS符合传感器模式；
5. 序号无持续跳变；
6. Ctrl+C安全退出；
7. 设备可以立即重新打开；
8. 画质通过同场景对比和亮度/色度统计；
9. 保留原文件、当前稳定文件和候选文件的SHA256。
